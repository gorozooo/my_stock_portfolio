# 家計簿アプリ 🏠

家族3人（家・ぼーや・ごろ）のお金の出し入れを管理するアプリです。  
スマホ・パソコンどちらからでも使えて、インターネットがあればどこからでもアクセスできます。

---

## このアプリでできること

### 画面一覧

| 画面 | できること |
|------|-----------|
| ダッシュボード | 今月のお金の流れをひと目で確認。収入・支出・貯蓄・口座残高・TODO・メモをまとめて表示 |
| 収入入力 | 給料・ボーナスなどの収入を登録。カテゴリ（給与・副業など）と対象者（家・ぼーや・ごろ）を選べる |
| 変動費入力 | クレジットカード払い・立替・年金保険・その他の支出を登録。カードと支払い方法を細かく管理 |
| 固定費管理 | 毎月かかる固定費（家賃・保険など）のテンプレートを管理。ひとつひとつ「今月は使わない」とオフにもできる |
| 口座残高 | 銀行・証券口座の残高を月ごとに記録。同じ月・同じ口座に入力したら自動で上書きされる |
| 収支分析 | 収入（緑）・固定費（紫）・変動費（赤）・立替（オレンジ）を色分けしてひと目で比較。棒グラフで割合も表示 |
| チャート | 12ヶ月分の収入と支出のグラフ（棒グラフ＋折れ線グラフ）と、カテゴリ別支出の円グラフ |
| 設定 | カテゴリ・口座・クレジットカードの追加・編集・削除 |
| データ管理 | 月を選んで登録済みデータの確認・修正・削除 |

---

### 各画面の詳しい説明

#### ダッシュボード
月を左右のボタンで切り替えながら、その月の収支まとめを確認できます。

- **収支サマリー**: 収入合計・支出合計・差額（収入 − 支出）を大きく表示
- **貯蓄 KPI**: 家の貯蓄額をリアルタイム計算して表示
- **口座残高**: 家・ぼーや・ごろそれぞれの口座残高一覧
- **TODO リスト**: 今月やることのメモ。チェックを入れると完了扱いになる
- **メモ**: 自由入力のメモ欄。書いたら自動で保存される（800ミリ秒後）
- **月確定ボタン**: その月の数字を「スナップショット」として記録。あとで振り返られる

#### 収入入力
対象者（家 / ぼーや / ごろ）、カテゴリ、金額、メモを入力して登録します。  
同じ月・同じ対象者・同じカテゴリで2回入力するとエラーになります（重複防止）。

#### 変動費入力
4種類の支払い方法から選べます：

| 種類 | 説明 |
|------|------|
| カード払い | クレジットカードで支払った費用 |
| 立替 | 家族の誰かが立て替えて払った費用 |
| 年金保険 | 個人年金や保険の支払い |
| その他 | 現金払いやその他の支出 |

カード払いを選ぶと、登録済みのクレジットカードから選べます。  
対象者を選ぶと、そのひとのカードだけに絞り込まれます。

#### 固定費管理
毎月定額でかかる費用（家賃・保険・サブスクなど）をテンプレートとして登録します。  
トグルボタンで「有効 / 無効」を切り替えられるので、解約したサービスは無効にしておけば金額が集計から外れます。

#### 収支分析
4つの色分けカードで収支の内訳を一目で把握：

- 緑のカード → 収入合計
- 紫のカード → 固定費合計（有効なもののみ）
- 赤のカード → 変動費合計（カード払い・年金保険・その他）
- オレンジのカード → 立替合計（誰かが立て替えた金額）

各カードにはカテゴリ別の内訳バーグラフも表示されます。

#### チャート
- **12ヶ月トレンド**: 直近12ヶ月の収入（緑）・支出（赤）の棒グラフ。青い折れ線は収支差（黒字額）
- **カテゴリ別円グラフ**: 月を選ぶと、その月の支出カテゴリ別内訳を円グラフで表示

## インターネットで使えるようにする方法（Vercel デプロイ）

> **Supabaseってなに？**  
> データ（家計のデータ）をインターネット上に安全に保存してくれるサービスです。無料で使えます。  
> 銀行の金庫のようなものだと思ってください。

> **Vercelってなに？**  
> 作ったアプリをインターネット上に公開してくれるサービスです。無料で使えます。  
> 「ホームページを公開する場所」だと思ってください。

---

### 準備するもの

- GitHubのアカウント（[github.com](https://github.com) で無料登録できます）
- メールアドレス

---

### ステップ1：Supabase でデータの保存場所を作る

**（このステップでやること：家計データを保存する「金庫」を作ります）**

1. [supabase.com](https://supabase.com) を開き、右上の「**Start your project**」をクリック
2. 「**Sign in with GitHub**」でGitHubアカウントでログイン
3. ダッシュボードに入ったら「**New project**」ボタンをクリック
4. 以下を入力して「**Create new project**」ボタンを押す：
   - **Name**: `kakeibo`（なんでもOK）
   - **Database Password**: 自分で決めたパスワード（メモしておく）
   - **Region**: `Northeast Asia (Tokyo)` を選ぶ（日本に近い方が速い）
5. プロジェクトが作られるまで1〜2分待つ

**テーブルを作る（データの「表」を作る作業です）**

6. 左のメニューから「**SQL Editor**」をクリック
7. 画面中央の入力欄に、このリポジトリの `supabase/schema.sql` の中身をすべてコピーして貼り付ける
8. 右上の「**Run**」ボタンを押す → 「**Success**」と表示されれば完了

**新規登録をできなくする（家族専用にする）**

9. 左メニュー「**Authentication**」→「**Settings**」→「**User Signups**」セクションを探す
10. 「**Enable email signups**」のスイッチを **オフ** にする → 「**Save**」を押す

---

### ステップ2：家族のアカウントを作る

**（このステップでやること：ログインできるユーザーを手動で追加します）**

1. Supabase の左メニュー「**Authentication**」→「**Users**」をクリック
2. 「**Add user**」→「**Create new user**」をクリック
3. 家族のメールアドレスとパスワードを入力して「**Create user**」ボタンを押す
4. 家族の人数分くり返す（全員が同じデータを見られます）

---

### ステップ3：Supabase の「秘密のパスワード」をメモする

**（このステップでやること：Vercel に教える「鍵」を手に入れます）**

1. Supabase の左メニュー「**Project Settings**」（歯車マーク）をクリック
2. 「**API**」タブを選ぶ
3. 以下の2つの値をメモしておく（あとでVercelに入力します）：

| メモする値 | どこにある？ |
|-----------|------------|
| **Project URL** | `https://xxxxxxxxxx.supabase.co` という形式の URL |
| **anon public** キー | `eyJhbGciO...` ではじまる長い文字列 |

---

### ステップ4：Vercel でアプリを公開する

**（このステップでやること：アプリをインターネットに公開します）**

1. [vercel.com](https://vercel.com) を開き、「**Start Deploying**」をクリック
2. 「**Continue with GitHub**」でGitHubアカウントでログイン
3. 「**Add New Project**」→「**Import Git Repository**」
4. 「**gorozooo/kakeibo**」を探して「**Import**」ボタンをクリック
5. **「Environment Variables」セクション** を探して、以下の2つを入力する：

| 入力欄の名前（Name） | 入力する値（Value） |
|---------------------|-------------------|
| `NEXT_PUBLIC_SUPABASE_URL` | ステップ3でメモした **Project URL** |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ステップ3でメモした **anon public キー** |

   > 入れ方：「**Name**」欄に左の文字を入力 → 「**Value**」欄に右のメモした値を貼り付け → 「**Add**」ボタンを押す。2つとも入力する。

6. 「**Deploy**」ボタンを押す
7. 画面が緑色の「**Congratulations!**」になったら完成！  
   `https://kakeibo-xxxxxxxxxx.vercel.app` のようなURLが発行されます

---

### ステップ5：動作確認

1. 発行された URL をブラウザで開く
2. ステップ2で作ったメールアドレス・パスワードでログイン
3. ダッシュボードが表示されれば成功！

---

### ステップ6：次回からの自動公開

GitHub の `main` ブランチにコードをアップするたびに、Vercel が自動でアプリを更新してくれます。  
（Vercel の「**Deployments**」タブで更新のログを確認できます）

---

### カスタムドメインを設定する（任意・やりたい人だけ）

Vercel の管理画面 → プロジェクト → 「**Settings**」→「**Domains**」から、  
`kakeibo.yourdomain.com` のような独自のURLを設定できます。

## 自分のパソコンで動かす方法（開発者向け）

### 1. 環境変数ファイルを作る

```bash
cp .env.local.example .env.local
```

`.env.local` をテキストエディタで開いて、Supabase のURL とキーを書き込む：

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
```

### 2. パッケージをインストールして起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開く。

### 3. ビルド確認

```bash
npm run build
```

エラーが出なければ本番環境でも動きます。

## 将来の拡張予定（日本株ポートフォリオ / 自動売買統合）

このアプリは将来的にポートフォリオ管理・自動売買管理を同一アプリに統合できるよう設計されています。

### 拡張イメージ

```
app/
├── (kakeibo)/      ← 今回実装（家計簿）
├── (portfolio)/    ← 将来：日本株ポートフォリオ管理
└── (autotrade)/    ← 将来：自動売買管理
```

- `app/(kakeibo)/` のルートグループが `app/(portfolio)/` などと **共存可能**
- Supabase のスキーマを `kakeibo.*`, `portfolio.*` と **スキーマ分離**して拡張予定
- 認証（Supabase Auth）は **全モジュールで共通**
- `lib/kakeibo/queries.ts` に portfolio テーブルへの参照拡張ポイントをコメントで設定済み
